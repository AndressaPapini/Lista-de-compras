## ✦ SOBRE O PROJETO ✦

</div>

O **Lista de Compras** é um site desenvolvido para facilitar a organização dos produtos que precisam ser comprados.

A proposta é criar uma experiência **simples, visual e intuitiva**, permitindo que o usuário tenha sua lista organizada em um único lugar.

O projeto também foi desenvolvido para colocar em prática conhecimentos de **HTML, CSS e JavaScript**, trabalhando estrutura, estilização, interação e responsividade.
